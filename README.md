# 🧪 Inorganic Chemistry

Welcome to the **Inorganic Chemistry** repository! ⚗️

This repository contains notes, important concepts, chemical reactions, formulas, and study materials related to inorganic chemistry. It is designed to help students understand concepts easily and revise important topics.

## 📚 Topics Covered

* 🧬 Periodic Table and Periodic Properties
* ⚛️ Atomic Structure
* 🔗 Chemical Bonding
* 🧪 Coordination Compounds
* 🔋 Electrochemistry
* 🧫 s-Block Elements
* 🧫 p-Block Elements
* ⚗️ d-Block and f-Block Elements
* 🔥 Metallurgy
* 🧾 Important Chemical Reactions
* 📖 Important Formulas and Short Notes

## 🎯 Objectives

* Understand the fundamental concepts of inorganic chemistry.
* Organize notes and study materials in one place.
* Make chemistry easier to learn and revise.
* Help students prepare for examinations.
* Encourage collaborative learning and knowledge sharing.

1. Clone or download this repository.
2. Open the topic you want to study.
3. Read the notes and practice the important questions.
4. Use the formulas and reactions for quick revision.
